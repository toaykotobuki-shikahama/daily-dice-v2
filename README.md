## フォルダ

- `01_design/` 構成・DB・依存関係・要件対応表・未解決事項
- `02_gas/public/` 新規公開GAS候補
- `02_gas/admin/` 新規管理GAS候補・ダイアログ・簡易/詳細テスト
- `03_pages/` 第一弾UI演出を引き継いだ新規Pages候補。接続URLはプレースホルダー

Node.js で `cd 04_tests && npm test` を実行します（静的チェック → ドメイン → GASモック結合 → Pages構文）。テスト結果はドメイン規則だけを対象にし、GAS、スプレッドシート、認証、ブラウザやLINE内ブラウザの合格を意味しません。

## このリポジトリ（toaykotobuki-shikahama/daily-dice-v2）

r3 パッケージを新規の検証用リポジトリとして配置したものです。旧 `daily-dice-challenge` とは別物で、互いに影響しません。

- `main` へ push すると Actions が `04_tests` の `npm test` を実行し、合格したときだけ `03_pages` を GitHub Pages に公開します。
- 検証中の保存キーは `daily-dice.identity.v2-verify` です。Pages は第一弾と同じオリジン（github.io）を共有するため、`v1` のままだと検証端末の第一弾の参加記録を上書きします。`v1` に戻すと静的チェックで止まります。
- セットアップは `05_operations/SETUP_CHECKLIST.md` を上から埋めてください。
