# 検証CSVを共有する時の依頼文

デイリーサイコロチャレンジの検証データを分析してください。

添付：詳細_試行ログ、サマリー、実施履歴、テスト定義CSV。アプリ版：____。テスト定義Ver：____。端末・回線：____。実施期間：____。

試行の開始有無を確認し、未開始は総試行数から除外してください。成功・失敗・中断・未確認を区別し、欠測を0msとして扱わないでください。同じ試行IDの重複がないか、開始済みで終了日時がない行がないかも確認してください。

同一のテスト定義・端末・回線でアプリ更新前後の回数、成功率、失敗率、平均、中央値、最大、P95を比較してください。取得できない項目は未取得としてください。GAS計測区間は要求受付から操作ログ書込直前までで、GAS実行全体時間ではありません。GAS往復は実操作executeのみ、管理通信は除外されています。区間は重なるため足して全体時間にしないでください。

異常の多い操作、所感と自動判定の食い違い、再取得や保存の未確認、不具合対応状況を優先順に整理してください。原因を断定せず、追加確認手順・修正案・同じ条件での再テスト案を提示してください。単独スタッフによるこのデータから最大同時接続人数を推定しないでください。
