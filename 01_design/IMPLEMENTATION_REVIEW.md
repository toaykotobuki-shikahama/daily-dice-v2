## 排他制御の変更点

管理GASと公開GASがそれぞれ独立ロックを使う設計をやめました。V2 DBの書込みは公開GASだけが行い、管理GASは確認済み操作者を付けてHMAC署名RPCを送ります。公開GASが署名・時刻・nonceを確認し、同じ `ScriptLock` を取得して最新設定の再取得、権限/状態検証、保存を行います。設定+監査、抽選履歴+カード、完了カード+確認ログはSheets API batchUpdateへまとめます。

この方式でプロジェクト間のロック共有依存は除去しました。HMAC鍵を両プロジェクトのScript Propertiesへ別途設定する必要があります。キーの生成・設定・通信、cache nonce、実行アカウント、Sheets API batchUpdateの権限/原子性、同時実行は未検証です。よってR05の設計対応は実装済み、R05の合格判定は未完了です。
